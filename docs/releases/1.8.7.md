# EPL Sync 1.8.7

## Novedades

- **Abrir los clientes desde EPL Sync.** Estado de las descargas incorpora Abrir qBittorrent y Biblioteca de Calibre incorpora Abrir Calibre. Ambos enlaces abren una pestaña nueva y aparecen cuando está configurada su URL del navegador. El cliente torrent admite la nueva variable `EPLSYNC_TORRENT_BROWSER_URL` y el campo URL del navegador en Ajustes.

## Mejoras y correcciones

- Los envíos a Calibre continúan con el siguiente libro después de verificar el anterior, reduciendo las pausas entre envíos.
- Cuando el cliente torrent está ocupado al leer un archivo, se aplaza ese libro y el trabajo sigue con los demás. Los reintentos usan esperas progresivas y conservan su estado tras reiniciar EPL Sync.
- La preparación de envíos masivos a Calibre reintenta el lote pendiente cuando el cliente torrent está ocupado y evita refrescar el índice completo en cada lote.
- Las métricas DEBUG registran por separado los tiempos de lectura, importación y verificación de cada envío a Calibre.
- El seguimiento de descargas vincula los registros por instancia del cliente, EPL ID y hash, conservando las revisiones del historial. Esto permite recuperar trabajos que mostraban No encontrado cuando el registro local tenía otra revisión para el mismo hash.
- Los botones de cabecera se alinean a la derecha también cuando ocupan varias filas.

## Actualización

La actualización desde 1.8.6 aplica automáticamente una migración de SQLite que añade el contador de reintentos por cliente torrent ocupado y un índice para los elementos pendientes de Calibre. Para los pasos de actualización, consulta la [guía de instalación](../instalacion.md).

Para mostrar Abrir qBittorrent, configura `EPLSYNC_TORRENT_BROWSER_URL` o URL del navegador en Ajustes de Torrent. Abrir Calibre reutiliza `EPLSYNC_CALIBRE_BROWSER_URL` o la URL del navegador guardada en sus ajustes. Una URL vacía oculta el botón.
