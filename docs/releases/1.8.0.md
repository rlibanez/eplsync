# EPL Sync 1.8.0

## Novedades

- Integración con Hardcover desde Biblioteca de Calibre, tanto para libros seleccionados como desde las acciones de cada fila.
- Búsqueda por título y autor, con prioridad para ISBN o ASIN válidos. Los criterios se pueden editar por libro sin cambiar sus metadatos en Calibre.
- Selección de obra y edición con filtro de idioma, carga de más resultados al desplazarse y ordenación explicada mediante tooltips. Las opciones muestran valoraciones de la obra y usuarios de la edición cuando Hardcover proporciona esos datos.
- Asignación de `hardcover`, `hardcover_book` y `hardcover_edition`, además de ISBN-10, ISBN-13 y ASIN opcionales, con nombres de destino configurables por usuario.
- Comprobación de un slug o ID de edición introducido manualmente, actualizando los datos relacionados antes de guardar.
- Configuración de la API key en Ajustes > Calibre > Hardcover, exclusiva de administradores. Permite guardar la clave cifrada, comprobar la conexión sin guardar y borrar la clave para desactivar la integración. Los cambios se aplican sin reiniciar.
- Enlace para obtener la API key, caducidad cuando el token incluye una fecha reconocible y aviso cuando ha caducado o le quedan siete días o menos.
- Uso y límite diarios a partir de las cabeceras de las respuestas normales de Hardcover, indicando la fecha de lectura y el restablecimiento, sin consultas adicionales ni sondeo.
- Portadas de Calibre, obra y edición con ampliación superpuesta y enlaces directos a Hardcover. El asistente permite volver al libro anterior y muestra posición y libros guardados.

## Mejoras y correcciones

- Previsualización de los identificadores actuales y propuestos. Solo se añaden valores ausentes: los identificadores existentes con valores diferentes se conservan y se muestran como conflictos.
- Comprobación de la entrada y los metadatos de Calibre antes de guardar. Los reintentos reconocen los cambios ya aplicados y no repiten la escritura.
- Caché de búsquedas, idiomas y ediciones, con paginación y sin peticiones GraphQL adicionales para mostrar portadas, contadores o tooltips.
- Búsquedas y previsualizaciones vinculadas a su usuario y biblioteca. Se respetan los permisos de lectura y envío a Calibre; la portada local requiere además permiso de lectura de archivos.
- La clave de Hardcover no se devuelve al navegador ni se muestra en registros. La configuración guardada tiene prioridad sobre el valor inicial de entorno.
- El aviso de clave ausente enlaza directamente con el apartado de configuración para administradores.
- La ampliación de portadas conserva el estado del asistente y se cierra con clic, Escape o el botón de cierre.
- Los EPUB originales y los de la biblioteca de Calibre no se modifican: únicamente se actualizan los identificadores de la base de datos de Calibre.

## Configuración

Introduce la API key en Ajustes > Calibre > Hardcover. Para guardarla se necesita `EPLSYNC_SECRET_KEY`. Como valor inicial también se admite `EPLSYNC_HARDCOVER_API_KEY` en `.env` o en el entorno del JAR. Consulta la [guía de Hardcover](../hardcover.md).

## Actualización

Realiza una copia de seguridad y conserva los datos persistentes y `EPLSYNC_SECRET_KEY`.

Desde 1.7.1 no se aplican nuevas migraciones: el esquema continúa en `1.7.0.7`. Se conservan los datos, trabajos, ajustes y búsquedas guardadas. Los SQL publicados mantienen sus nombres y contenidos. Las preferencias personales y la clave cifrada de Hardcover utilizan la tabla existente `app_settings`.
